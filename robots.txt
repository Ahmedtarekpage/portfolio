# ahmedtarek.tech
#
# Everything public is open to everyone, search engines and answer engines
# alike — being quoted by an assistant is how a growing share of people arrive,
# and there is nothing here worth hiding from a crawler.
#
# The named groups are not decoration. A crawler that finds a group matching
# its own name obeys that group and ignores "User-agent: *" completely — so
# naming a bot in order to welcome it, without repeating the private paths
# underneath, would quietly hand it the pages meant to stay out of search.
# Hence the same block, repeated, for every agent named here.
#
# What is disallowed: the passkey-gated tools, and the client share links.
# Those refuse without a passkey and carry noindex already, but a share token
# turning up in a search result would expose a client's own page.
